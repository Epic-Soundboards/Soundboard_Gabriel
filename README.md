# 🔊 Praktikanten-Projekt: Meme Soundboard

Willkommen im Praktikum! Dies ist dein Start-Projekt. 
Du wirst heute eine eigene Soundboard-Webseite bauen, die du am Ende auf deinem Smartphone nutzen kannst.

## 🛠 Deine Aufgaben für heute:
1. **Sounds finden:** Lade lustige Sounds als `.mp3` herunter (https://pixabay.com/sound-effects/ oder https://freesound.org/ ) und speichere sie im Ordner `sounds/`.
2. **Bilder finden:** Finde passende Icons oder Bilder und speichere sie in `bilder/`.
3. **Buttons bauen:** Öffne die `index.html` und kopiere den Code-Block für die Buttons. Trage deine neuen Dateinamen ein.
4. **Design anpassen:** Öffne die `style.css` und verändere die Farben, Ecken und Schriftarten nach deinem Geschmack!

Viel Spaß beim Coden! 🚀
